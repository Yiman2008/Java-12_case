## Практическая работа № 3

SQLReport 0.3.0 выполняет один запрос к CSV с заголовком в UTF-8. Поддерживает `SELECT`, `WHERE` (сравнения с литералами, `AND`, `OR`, скобки), `GROUP BY`, агрегаты `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`, `ORDER BY` по имени из `SELECT` и `LIMIT`. Имена столбцов чувствительны к регистру. Имена с пробелами и пути с пробелами указываются в двойных кавычках, строковые значения — в одинарных. Среднее округляется до двух знаков, пустые поля пропускаются при сравнении и в агрегатах, кроме `COUNT(*)`.

### Сборка и запуск

Требуются JDK 17 или новее и Maven 3.9+. Выполняйте команды из корня репозитория.

```sh
mvn clean package
java -jar target/sqlreport-0.3.0.jar --help
java -jar target/sqlreport-0.3.0.jar -q "SELECT name, AVG(grade) AS avg_grade, COUNT(*) AS n FROM examples/students.csv WHERE grade >= 3 GROUP BY name ORDER BY avg_grade DESC LIMIT 2;"
```

```text
name  | avg_grade | n
Anna  | 4.5       | 2
Boris | 4         | 2
```

Для экспорта в новый файл:

```sh
java -jar target/sqlreport-0.3.0.jar --format HTML --out report.html -q "SELECT * FROM examples/students.csv;"
```

Форматы `TABLE`, `CSV`, `HTML` и `MARKDOWN`. При отсутствии `--out` отчёт выводится в консоль. Дальнейшие итерации по SRS включают JOIN, HAVING, режим командного сеанса, графический интерфейс, визуализацию и экспорт графиков в PNG. Пример из первой контрольной работы хранится в `KR1/`.

### Пакеты и зависимости

| Пакет | Назначение |
| --- | --- |
| `cli` | Опции командной строки и вывод |
| `parser`, `ast` | Разбор запроса и дерево условий |
| `data`, `model` | Чтение CSV и табличная модель |
| `execution` | Фильтрация, проекция, агрегация и сортировка |
| `output` | Форматирование результата |

- picocli 4.7.7 — разбор параметров и справка CLI.
- JUnit Jupiter 5.11.4 — тесты, выполняемые при сборке. В исполняемый JAR JUnit не включается.
- Maven Shade Plugin — сборка JAR с зависимостью picocli.
