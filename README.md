## Тема проекта № 12 — «Генератор отчётов на основе SQL-подобного языка» (SQLReport)

Библиотека и консольная программа на Java, которая принимает запрос вида

```sql
SELECT name, avg(grade) AS avg_grade FROM students.csv GROUP BY name ORDER BY avg_grade DESC;
```

читает CSV-файлы, выполняет выборку, фильтрацию, соединение, группировку с агрегатными функциями,
сортировку и выводит отчёт — таблицу в консоли или файл CSV / HTML / Markdown.
